## ✨ Features

- **Minimal, Modern Design** — Apple + Vercel + Linear inspired dark theme
- **Dark Mode First** — Premium dark UI with `#09090B` background
- **Glassmorphism** — Subtle backdrop blur effects on cards and navbar
- **Smooth Animations** — Scroll reveal, typing effect, floating shapes, hover lift
- **Mouse Glow Effect** — Interactive radial gradient that follows the cursor
- **Loading Screen** — Animated loading bar on initial page load
- **Fully Responsive** — Desktop, tablet, and mobile breakpoints
- **Hamburger Menu** — Mobile navigation with slide-in drawer
- **Skill Progress Bars** — Animated skill bars with Intersection Observer
- **Counter Animation** — Number counters on quick facts
- **Contact Form** — Client-side validation with visual feedback
- **Scroll to Top** — Floating button appears on scroll
- **SEO Optimized** — Meta tags, Open Graph, semantic HTML, ARIA labels
- **Accessibility** — ARIA roles, keyboard navigation, reduced motion support
- **Print Styles** — Clean print layout included

## 🚀 Getting Started

1. **Clone or download** the repository
2. **Open `index.html`** in your browser — no build step needed
3. Optionally, add your **profile photo** and **CV PDF**:
   - Replace `assets/images/` with your photo
   - Update the `Download CV` link in `index.html` to point to `assets/cv.pdf`
